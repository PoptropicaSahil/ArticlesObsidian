
## Unsupervised Learning — Representation Learning

> *"Comprehension is compression"* — George Chaitin

Running theme: if you can compress data while retaining what matters, you have learned something ⇒ ask of every algorithm: **where is the compression happening?**

**Input:** $n$ data points $x_1, \ldots, x_n \in \mathbb{R}^d$ <br>
**Goal:** find a *compressed representation* of the dataset

---

## Lecture 1 — Compression via a line

**Example:** 4 points in $\mathbb{R}^2$

$x_1 = [-7, -14]$, $x_2 = [2.5, 5]$, $x_3 = [0.5, 1]$, $x_4 = [0, 0]$

Naive storage: $4 × 2 = 8$ numbers

Observation: 2nd coordinate = $2 ×$ 1st coordinate ⇒ all points lie on the line $y = 2x$

**Compressed:** one representative $w = [1, 2]$ + one scalar $c_i$ per point

$x_1 = -7\,w$, $x_2 = 2.5\,w$, $x_3 = 0.5\,w$, $x_4 = 0\,w$ ✓ (exact reconstruction)

Storage $= d + n$ instead of $d × n$ (at $n = 10^9$: $\sim 10^9$ vs $2 × 10^9$ → ~50% compression)

> Representative is not unique. Any non-zero vector along the line works (e.g. $[1/\sqrt{5}, 2/\sqrt{5}]$), coefficients just rescale. Convention: pick $\Vert{}w\Vert{} = 1$

**If a point falls off the line**

- Exact reconstruction with one representative is impossible
- Adding more representatives ⇒ more coefficients per point ⇒ compression lost
- **Resolution:** give up exact reconstruction → use the best *proxy* on the line = its **projection**

### Projection onto a line

Representative $w$ with $\Vert{}w\Vert{} = 1$, point $x$

$c^* = \arg\min_c \Vert{}x - cw\Vert{}^2$ <br>
$⇒ c^* = \dfrac{x^\top w}{\Vert{}w\Vert{}^2} = x^\top w$ (as $\Vert{}w\Vert{} = 1$) <br>
$⇒ \hat{x} = (x^\top w)\,w$ (proxy)

> Check golden algebra for proof (simple only)

Residual $x - \hat{x}$ is **orthogonal to $w$**

![[ArunRajkumar_PRML/Drawing 2026-11-08 18.37.34.excalidraw]]


| Representation | Numbers stored |
|---|---|
| Naive (exact) | $d × n$ |
| 1 representative + coefficients (exact, all on a line) | $d + n$ |
| 1 representative + coefficients (approx, via projection) | $d + n$ |

> Tradeoff: **exact reconstruction vs compression**. Projection adds error but keeps compressibility

Next: which line $w$ minimises total reconstruction error over all $n$ points? ⇒ PCA

## Lecture 2 — Finding the best line

Unit vector $w$ ($\Vert{}w\Vert{} = 1$) = line through the origin. Proxy of $x_i$ is $(x_i^\top w)w$

$f(w) = \dfrac{1}{n}\sum_{i=1}^n \Vert{}x_i - (x_i^\top w)w\Vert{}^2$ (… residual sum of errors to **MINIMISE**) 

Expand using $w^\top w = 1$

$f(w) = \dfrac{1}{n}\sum_{i=1}^n \left[\Vert{}x_i\Vert{}^2 - (x_i^\top w)^2\right]$

First term does not depend on $w$ → constant

$⇒ \min_{\Vert{}w\Vert{}=1} f(w) \equiv \max_{\Vert{}w\Vert{}=1} \dfrac{1}{n}\sum_{i=1}^n (x_i^\top w)^2$

> **Minimising reconstruction error = maximising variance of projections** (data centred, see below)

**Covariance matrix $C \in \mathbb{R}^{d×d}$**

$(x_i^\top w)^2 = w^\top x_i x_i^\top w$

> Variance is given by $w^\top C w$

$\max_{\Vert{}w\Vert{}=1}\; w^\top C w$, where $C = \dfrac{1}{n}\sum_{i=1}^n x_i x_i^\top \in \mathbb{R}^{d×d}$

- $C$ = average of rank-1 outer products $x_i x_i^\top$, one per data point
> We follow row notation for now i.e. $X \in \mathbb{R}  ^{n × d} \implies C = X^\top X$ <br>
> If $X \in \mathbb{R}  ^{d × n} \implies C = X X^\top$ … ( stack datapoints as columns)
-

**Solution** (standard linear algebra result, proof later)

$w^* = \arg\max_{\Vert{}w\Vert{}=1} w^\top C w$ = **eigenvector of $C$ with the largest eigenvalue**

![](Pasted%20image%2020261108055349.png)

| Object | What it is |
|---|---|
| $C = \frac{1}{n}\sum x_i x_i^\top$ | $d×d$ covariance matrix |
| $w^*$ | top eigenvector of $C$ |
| $\lambda_{\max}$ | variance of projections along $w^*$ |

> Nobody hands you the line. Form $C$ from data, take its top eigenvector ⇒ PCA with 1 component

## Lecture 3 — Beyond one line

**Problem with a single line:** data on a **2D plane inside 3D**. Best line captures one direction, but the residuals align along *another* direction

> Aligned residuals = **information, not noise** (pure noise ⇒ random directions)

![](Pasted%20image%2020261108055538.png)

**Iterative algorithm (sketch)**

1. **Center:** $x_i \leftarrow x_i - \bar{x}$, $\bar{x} = \dfrac{1}{n}\sum x_i$ <br>
   *(without this, lines through the origin chase the mean, not the spread)*
2. **Find $w_1$:** $\max_{\Vert{}w\Vert{}=1} w^\top C w$ → top eigenvector of $C$
3. **Residuals:** $e_i = x_i - (x_i^\top w_1)w_1$
4. **Repeat** on $\{e_i\}$ → $w_2$, $w_3$, … up to $k$ times

**Four open questions** (define PCA)

1. How to solve $\max_{\Vert{}w\Vert{}=1} w^\top C w$? (eigenvector claim needs proof)
2. How many repeats, i.e. what is $k$?
3. Where is the compression in the multi-line version?
4. What is the final learned representation? (multiple $w$ ⇒ multiple coefficients ⇒ what structure?)

## Lecture 4 — Orthogonality, reconstruction, stopping

**Key result: $w_1 \perp w_2$**

- All residuals after round 1 are orthogonal to $w_1$ (geometry of projection)
- ⇒ best line through them is also orthogonal to $w_1$: $w_2^\top w_1 = 0$
- Each new $w_k$ is orthogonal to all previous ones
- After $d$ rounds in $\mathbb{R}^d$ ⇒ full **orthonormal basis** $\{w_1, \ldots, w_d\}$

$\Vert{}w_k\Vert{}^2 = 1\ \ \forall k$, $\quad w_i^\top w_j = 0\ \ \forall i \neq j$

**Change of basis**

After $d$ rounds residuals $= \mathbf{0}$ ⇒ exact reconstruction

$x_i = (x_i^\top w_1)w_1 + (x_i^\top w_2)w_2 + \cdots + (x_i^\top w_d)w_d$ <br>
$x_i = (c_1)w_1 + (c_2)w_2 + \cdots + (c_d)w_d$

Just a **change of basis** (standard → $\{w_j\}$). By itself not compression

**Where compression happens**

Data in (or near) a $k$-dim subspace ⇒ residuals hit $\mathbf{0}$ after $k \ll d$ rounds

$x_i \approx (x_i^\top w_1)w_1 + \cdots + (x_i^\top w_k)w_k$

Storage = $k$ representatives ($kd$)  (each of $w_i$)+ $k$ coefficients per point ($kn$) ( each of $c_i$)

| | Numbers stored |
|---|---|
| Naive | $d × n$ |
| $k$ representatives + coefficients | $kd + kn$ |

e.g. $d = 100$, $k = 3$: $100n$ vs $300 + 3n$ ⇒ at $n = 100$: $10{,}000 → 600$. Coefficients per point shrink $d → k$

### Pythagoras ⇒ stopping criterion

For unit $w$ and any point $x_i$

$\Vert{}x_i\Vert{}^2 = \Vert{}x_i - (x_i^\top w)w\Vert{}^2 + (x_i^\top w)^2$ ⇒ $\text{length}^2 = \text{error}^2 + \text{projection}^2$

> Evident from the diagram too

Average over the dataset, round $k$

$\dfrac{1}{n}\sum_i \Vert{}x_i\Vert{}^2 = \text{avg error}^2(w_k) + \underbrace{\dfrac{1}{n}\sum_i (x_i^\top w_k)^2}_{\lambda_k}$

> In round $k$, $x_i$ = current residuals ⇒ LHS is constant within the round

- $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_d \geq 0$ (if round $k+1$ could do better than round $k$, round $k$ would have found it)
- Residuals $\to 0$ after $d$ rounds ⇒ $\sum_{j=1}^d \lambda_j = \dfrac{1}{n}\sum_i \Vert{}x_i\Vert{}^2$ (total variance)

![](Pasted%20image%2020261108055700.png)

**Rule of thumb:** smallest $k$ with

$\dfrac{\sum_{j=1}^k \lambda_j}{\sum_{j=1}^d \lambda_j} \geq 0.95$

⇒ top $k$ components explain 95% of total variance. Elbow in the scree plot = visual version of this

### Full algorithm (PCA)

1. **Center:** $x_i \leftarrow x_i - \bar{x}$
2. **Covariance:** $C = \dfrac{1}{n}\sum_{i=1}^n x_i x_i^\top \in \mathbb{R}^{d×d}$
3. **Top $k$ eigenvectors** $w_1, \ldots, w_k$ of $C$ (orthonormal basis)
4. **Encode:** $x_i \mapsto [x_i^\top w_1, \ldots, x_i^\top w_k] \in \mathbb{R}^k$
5. **Reconstruct:** $\hat{x}_i = \sum_{j=1}^k (x_i^\top w_j)\,w_j$

$w_j$ = **principal components**; algorithm = **PCA**

Still open: why does the eigenvector of $C$ solve the max problem? ⇒ spectral theory (next)

## Lecture 5 — Linear algebra connections

**Hilbert min-max theorem:** iterative residual procedure ≡ eigendecomposition

- $w_1$ = eigenvector of $C$ with **largest** eigenvalue $\lambda_1$
- $w_k$ = eigenvector with $k$-th largest eigenvalue $\lambda_k$ = exactly the line found in round $k$
- Eigenvectors of $C$ form a complete **orthonormal basis** of $\mathbb{R}^d$

**Meaning of eigenvalues** (centred data)

$\lambda_k = w_k^\top C w_k = \dfrac{1}{n}\sum_{i=1}^n (x_i^\top w_k)^2$

Data centred ⇒ $\dfrac{1}{n}\sum_i x_i^\top w_k = 0$ ⇒ this is exactly the **variance of projections** onto $w_k$

> [!NOTE] Takeaway
> $\lambda_k$ = variance of data projected onto the $k$-th principal component

**Three equivalent views of PCA**

$\min_{\Vert{}w\Vert{}=1} \dfrac{1}{n}\sum_i \Vert{}x_i - (x_i^\top w)w\Vert{}^2$ … minimise reconstruction error <br>
$\equiv \max_{\Vert{}w\Vert{}=1} \dfrac{1}{n}\sum_i (x_i^\top w)^2$ … maximise projection variance <br>
$\equiv \max_{\Vert{}w\Vert{}=1} w^\top C w$ … top eigenvector of $C$

All give the same $w^*$. Variance view = cleanest geometric intuition

**Why variance maximisation makes sense**

Wrong line ⇒ projections crowd together ⇒ can't tell points apart. Right line spreads projections maximally ⇒ keeps most discriminative information for downstream tasks

![](Pasted%20image%2020261108060358.png)

**PCA as decorrelation (height/weight)**

Height and weight are correlated (overlapping information). PCA finds

$w_1 = \left[\tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}\right] ⇒ \text{score}_1 = \dfrac{\text{height} + \text{weight}}{\sqrt{2}}$ <br>
$w_2 = \left[-\tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}}\right] ⇒ \text{score}_2 = \dfrac{\text{weight} - \text{height}}{\sqrt{2}}$

New axes are **decorrelated**: $w_j^\top C w_k = \lambda_k w_j^\top w_k = 0$ for $j \neq k$ ⇒ each direction carries genuinely new information

**PCA summary**

| Concept | Statement |
|---|---|
| Input | Centred data $\{x_i\} \subset \mathbb{R}^d$ |
| Covariance | $C = \frac{1}{n}\sum_i x_i x_i^\top \in \mathbb{R}^{d×d}$, PSD |
| Principal components | Eigenvectors $w_1, \ldots, w_k$ of $C$ (orthonormal) |
| Eigenvalues | $\lambda_k$ = variance of projections on $w_k$, all $\geq 0$ |
| Encoding | $x_i \mapsto [x_i^\top w_1, \ldots, x_i^\top w_k] \in \mathbb{R}^k$ |
| Reconstruction | $\hat{x}_i = \sum_{j=1}^k (x_i^\top w_j)\,w_j$ |
| Stopping rule | smallest $k$ with $\frac{\sum_{j\leq k} \lambda_j}{\sum_{j\leq d} \lambda_j} \geq 0.95$ |
| Does | Dim. reduction $\mathbb{R}^d \to \mathbb{R}^k$, decorrelates features |

## Lecture 6 — Eigenfaces & limitations of PCA

### Eigenfaces

- Image $192 × 168$ grayscale → flatten → $x_i \in \mathbb{R}^{32256}$;  ~20,000 faces m; run standard PCA
	- $d=32256$ and $n=20000$
- Each $w_k \in \mathbb{R}^{32256}$ **reshaped back to an image** = **eigenface**
- $w_1$ = "most face-like" direction (template common to all faces)
- $w_2, w_3, \ldots$ = progressively finer details (lighting, nose shape, eye spacing, …)

| Components $k$ | Human face | Dog face |
|---|---|---|
| 25 | Recognisably a face, not who | Unrecognisable |
| 200–300 | Enough for identity | Still poor |
| 1600 | Near-perfect | Reasonable |
| 32256 | Exact | Exact |

- Top eigenfaces span a *human-face subspace* ⇒ a dog projected onto it = "most human-looking version" of that dog
- Feature, not a bug: even $k = 25$ separates human vs dog (the dog's reconstruction looks like neither)

> **Use:** store only $k \approx 200$–$300$ projections instead of 32,256 pixels (~100× compression) → feed to a supervised classifier

### Two problems with PCA

**1. Time complexity**

Bottleneck = eigenvectors of $C \in \mathbb{R}^{d×d}$ ⇒ $\text{Time} = O(d^3)$

$d = 32{,}000$ ⇒ $d^3 \approx 3 × 10^{13}$ ops. Prohibitive for large $d$ (images, genomics, text)

**2. Linearity**

PCA finds the best *linear* subspace. Nonlinear feature relationships (e.g. BMI $\sim$ weight/height²) ⇒ data on a **curved manifold**, not a flat subspace

![](Pasted%20image%2020261108060606.png)

PCA on manifold data either reports high residual error (looks like more dimensions needed) or wastes dimensions on the "flattest" approximation of the curve ⇒ misses true low-dim structure

| | Problem 1 (time) | Problem 2 (nonlinearity) |
|---|---|---|
| Root cause | $C$ is $d×d$, $d$ huge | Data on curved manifold |
| Symptom | $O(d^3)$ intractable | PCA finds wrong structure |
| Fix | ??? | ??? |

> **Surprising claim:** the *same* fix addresses both. Solving the time problem hands us the machinery for nonlinear structure

## Lecture 7 — Kernel trick setup (Problem 1)

> [!NOTE] Back to the BEST convention
> Columns are data points ⇒ $X = [x_1 \mid \cdots \mid x_n] \in \mathbb{R}^{d×n}$ <br>
> $C = \dfrac{1}{n}XX^\top \in \mathbb{R}^{d×d}$ <br>
> Eigenvectors of $C$ = eigenvectors of $XX^\top$ (eigenvalues scale by $n$)

**Key observation:** for eigenvector $w_k$ of $C$ with $\lambda_k \neq 0$, put $C = \frac{1}{n}XX^\top$ in $Cw_k = \lambda_k w_k$ and rearrange

> *From Golden Algebra*

$Cw_k = \lambda_k w_k$ <br>
$⇒ \dfrac{1}{n}XX^\top w_k = \lambda_k w_k$ <br>
$⇒ w_k = X \left[ \dfrac{1}{n\lambda_k} X^\top w_k \right]$ <br>
$⇒ w_k = X\alpha_k$, with $\alpha_k = \dfrac{1}{n\lambda_k}X^\top w_k \in \mathbb{R}^n$ …(vector = Matrix × vector)

> **Every eigenvector is a linear combination of the data points.** Finding $w_k$ ⇒ finding weights $\alpha_k \in \mathbb{R}^n$

**Smaller eigen-problem**

$K = X^\top X \in \mathbb{R}^{n×n}$, $K_{ij} = x_i^\top x_j$

Substitute $w_k = X\alpha_k$ in the eigenvector equation, pre-multiply by $X^\top$

$K^2\alpha_k = (n\lambda_k)K\alpha_k$ <br>
$⇒ K\alpha_k = (n\lambda_k)\alpha_k$

$\alpha_k$ = **eigenvector of $K$** with eigenvalue $n\lambda_k$

> Fact: non-zero eigenvalues of $XX^\top$ and $X^\top X$ are identical ⇒ eigenvalues of $K$ are exactly $n\lambda_1, n\lambda_2, \ldots$

**Length normalisation**

$\beta_k$ = unit eigenvector of $K$ (from standard eigen-decomposition). Need $w_k^\top w_k = \alpha_k^\top K \alpha_k = 1$, but $\beta_k^\top K \beta_k = n\lambda_k \neq 1$ ⇒ $\beta_k \neq \alpha_k$

$\alpha_k = \dfrac{\beta_k}{\sqrt{n\lambda_k}}$ ⇒ $w_k = X\alpha_k$ has unit length ✓

**Efficient algorithm ($d \gg n$)**

| Step | Operation | Cost |
|---|---|---|
| 1 | $K = X^\top X$ | $O(n^2 d)$ |
| 2 | Eigen-decompose $K \in \mathbb{R}^{n×n}$ | $O(n^3)$ |
| 3 | $\alpha_k = \beta_k / \sqrt{n\lambda_k}$ | $O(nk)$ |
| 4 | $w_k = X\alpha_k$ (if needed) | $O(ndk)$ |

$O(d^3)$ on $d×d$ → $O(n^3)$ on $n×n$. Big saving when $n \ll d$

> Not automatic: $d = 32000$, $n = 20000$ ⇒ $d^3/n^3 \approx 4×$ only. (Lecture said ≈3×)

![](Pasted%20image%2020261108060700.png)

**Setup for Issue 2**

$K_{ij} = x_i^\top x_j$ = pairwise dot product (similarity)

⇒ The whole PCA solution depends only on $n×n$ pairwise similarities, not on raw $d$-dim vectors

⇒ Replace $x_i^\top x_j$ by a similarity that captures nonlinear structure ⇒ nonlinear PCA without working in high dimensions explicitly. That replacement = **kernel function** (next)

## Lecture 8 — Nonlinearity & feature maps (Problem 2)

**PCA fails on circular data**

- No direction is more important ⇒ PCA reports $w_1, w_2$ both needed (~50% variance each) ⇒ looks 2D
- But data is intrinsically **1D** (one angle $\theta$ parameterises the circle). Structure is nonlinear

**Core idea:** map to higher dim where the structure becomes **linear**

$\phi: \mathbb{R}^d \to \mathbb{R}^D$, $D \gg d$

**Circle example:** $(f_1 - a)^2 + (f_2 - b)^2 = r^2$

$⇒ f_1^2 + f_2^2 - 2af_1 - 2bf_2 + (a^2 + b^2 - r^2) = 0$

$\phi(x) = [1,\ f_1^2,\ f_2^2,\ f_1 f_2,\ f_1,\ f_2]^\top \in \mathbb{R}^6$ <br>
$u = [a^2 + b^2 - r^2,\ 1,\ 1,\ 0,\ -2a,\ -2b]^\top$ (fixed vector)

$⇒ \phi(x)^\top u = 0$ for every $x$ on the circle

> In $\mathbb{R}^6$ all mapped points are orthogonal to $u$ ⇒ they lie in a linear subspace. **Nonlinear constraint became linear**

Run PCA on $\{\phi(x_i)\}$ (if $D \gg n$, use the efficient $K = \Phi^\top\Phi$ route from before)

![](Pasted%20image%2020261108060944.png)

**The curse: dimension of $\phi$**

$d$ features, polynomial relations up to degree $p$ ⇒ all monomials up to degree $p$

$\dim(\phi) = \dbinom{d + p}{p} \sim O(d^p)$

| $d$ | $p$ | $\dim(\phi)$ |
|---|---|---|
| 2 | 2 | $6$ (circle example ✓) |
| 4 | 3 | $35$ |
| 10 | 15 | $\approx 3 × 10^6$ |
| 100 | 5 | $\approx 10^8$ |

> Correction: lecture wrote $\sum_{i=0}^p \binom{d}{i}$ (counts only products of *distinct* features) with table values $15$, $10^{15}$, $10^6$. These don't match monomial counts (e.g. circle gives 4, not 6). Growth $\sim d^p$ is the same

Even with $O(n^3)$ PCA, forming $K_{ij} = \phi(x_i)^\top\phi(x_j)$ needs dot products in $\mathbb{R}^D$ ⇒ intractable for huge $D$

**Setup for the kernel trick**

Efficient PCA only needs $K_{ij} = \phi(x_i)^\top\phi(x_j)$

**Key question:** can we compute it cheaply, without ever computing $\phi(x)$?

If $k(x_i, x_j) = \phi(x_i)^\top\phi(x_j)$ ⇒ just evaluate scalar $k$ on pairs of original points ⇒ **kernel function** (next). Fixes the dimensionality explosion and gives nonlinear PCA

## Lecture 9 — Kernel PCA

**Input:** $\{x_1, \ldots, x_n\} \subset \mathbb{R}^d$, kernel $k(x_i, x_j) = \phi(x_i)^\top\phi(x_j)$

**Step 1 — Compute and center $K$**

$K_{ij} = k(x_i, x_j)$

$K^c_{ij} = K_{ij} - \theta_i - \theta_j + \bar{K}$

- $\theta_i = \dfrac{1}{n}\sum_j K_{ij}$ (mean of row $i$)
- $\bar{K} = \dfrac{1}{n^2}\sum_{i,j} K_{ij}$ (grand mean)

Mimics subtracting $\mu = \dfrac{1}{n}\sum_i \phi(x_i)$ in mapped space, without computing $\phi$

$K^c_{ij} = (\phi(x_i) - \mu)^\top(\phi(x_j) - \mu)$

**Step 2 — Eigen-decompose $K^c$** ⇒ eigenvectors $\beta_1, \ldots, \beta_l$, eigenvalues $n\lambda_1 \geq \cdots \geq n\lambda_l$

**Step 3 — Normalise:** $\alpha_k = \dfrac{\beta_k}{\sqrt{n\lambda_k}}$

**Step 4 — Projections (no $\phi$ needed)**

$k$-th coordinate of point $x_i$

$\phi(x_i)^\top w_k = \sum_{j=1}^n \alpha_{kj}\,K^c_{ij}$

> Here $\phi$ is the centred one ($\phi(x_i) - \mu$). It is the $i$-th row of $K^c$ weighted by $\alpha_k$

$x_i \in \mathbb{R}^d \mapsto [\phi(x_i)^\top w_1, \ldots, \phi(x_i)^\top w_l] \in \mathbb{R}^l$

**Why we can't reconstruct (and don't need to)**

| | Standard PCA | Kernel PCA |
|---|---|---|
| Eigenvectors $w_k$ | Explicit, in $\mathbb{R}^d$ | Implicit, in $\mathbb{R}^D$ ($D$ possibly $\infty$) |
| Projections $x_i^\top w_k$ | Direct | Via kernel ✓ |
| Reconstruction $\hat{x}_i$ | Possible | **Not possible** (needs $\phi$) |
| Downstream use | ✓ | ✓ projections suffice |

> Preprocessing before supervised learning only needs the projections

**Why the kernel trick works**

Entire efficient PCA depended only on $K_{ij} = x_i^\top x_j$ ⇒ swap in $k(x_i, x_j) = \phi(x_i)^\top\phi(x_j)$ ⇒ PCA in mapped space for free

**Mercer's theorem:** if $k$ is valid (symmetric, PSD) ⇒ *some* $\phi$ exists with $k(x_i, x_j) = \phi(x_i)^\top\phi(x_j)$. No need to know $\phi$

| Kernel | $k(x, y)$ | Maps to |
|---|---|---|
| Linear | $x^\top y$ | Original space (standard PCA) |
| Polynomial, degree $p$ | $(x^\top y + c)^p$ | All monomials up to degree $p$ |
| RBF / Gaussian | $\exp\left(-\dfrac{\Vert{}x - y\Vert{}^2}{2\sigma^2}\right)$ | Infinite-dim space |

RBF implicitly captures *all* polynomial degrees at once ⇒ infinite $\phi$, finite $k$

![](Pasted%20image%2020261108061104.png)

**"Kernelizable" pattern**

Algorithm depends only on pairwise dot products $x_i^\top x_j$ ⇒ replace by $k(x_i, x_j)$ ⇒ nonlinear version for free. Seen again later (SVMs, kernel regression, …). Ask of any algorithm

1. Does it depend only on pairwise dot products?
2. If yes ⇒ which kernel captures the right notion of similarity for this problem?

**End of representation learning block**

| Algorithm | Structure found | Key matrix | Cost |
|---|---|---|---|
| PCA | Linear subspace | $C = \frac{1}{n}XX^\top$, $d×d$ | $O(d^3)$ |
| Efficient PCA ($d \gg n$) | Linear subspace | $K = X^\top X$, $n×n$ | $O(n^3)$ |
| Kernel PCA | Nonlinear manifold | $K^c$, $n×n$ | $O(n^3)$ |

## Lecture 10–11 — Kernels: the formal theory

**Example first:** $x = [f_1, f_2]^\top$, $x' = [g_1, g_2]^\top$

$(x^\top x' + 1)^2 = f_1^2 g_1^2 + f_2^2 g_2^2 + 1 + 2f_1 g_1 f_2 g_2 + 2f_1 g_1 + 2f_2 g_2$

$= \phi(x)^\top\phi(x')$ with

$\phi([f_1, f_2]) = [f_1^2,\ f_2^2,\ 1,\ \sqrt{2}f_1 f_2,\ \sqrt{2}f_1,\ \sqrt{2}f_2]^\top \in \mathbb{R}^6$

> $(x^\top x' + 1)^2$ = dot product in $\mathbb{R}^6$ using only the original 2D vectors, no explicit $\phi$ ⇒ **the kernel trick**

**Definition:** $k: \mathbb{R}^d × \mathbb{R}^d \to \mathbb{R}$ is a **kernel** if $\exists\ \phi: \mathbb{R}^d \to \mathbb{R}^D$ (possibly $D = \infty$) with

$k(x, x') = \phi(x)^\top\phi(x')$

**Polynomial kernel:** $k(x, x') = (x^\top x' + 1)^p$

- $\mathbb{R}^d \to \mathbb{R}^D$, $D = \dbinom{d + p}{p} \sim O(d^p)$ (corrected as above; $d = p = 2$ ⇒ 6 ✓)
- Captures all monomial relationships up to degree $p$

**RBF / Gaussian kernel:** $k(x, x') = \exp\left(-\dfrac{\Vert{}x - x'\Vert{}^2}{2\sigma^2}\right)$

- Maps to an *infinite*-dim space (Taylor expansion of $e^x$ ⇒ every polynomial degree present)
- Dot product there = infinite sum / integral, yet $k(x, x')$ is just a scalar ⇒ computed instantly
- Intuition: $k \approx 1$ when $x \approx x'$, decays to $0$ as points move apart. Bandwidth $\sigma$ = how fast similarity decays (tunable hyperparameter)

### Verifying a valid kernel — Mercer's theorem

Exhibiting $\phi$ works but can be hard. Mercer: $k$ is valid **iff**

- **(a) Symmetry:** $k(x, x') = k(x', x)$ for all $x, x'$
- **(b) PSD:** for any dataset $\{x_1, \ldots, x_n\}$, $K_{ij} = k(x_i, x_j)$ has all eigenvalues $\geq 0$

**Why necessary**

- Symmetry: $\phi(x)^\top\phi(x') = \phi(x')^\top\phi(x)$ (dot product is symmetric)
- PSD: $K = \Phi^\top\Phi$ ⇒ $v^\top K v = \Vert{}\Phi v\Vert{}^2 \geq 0$ <br>
  (covariance-type matrix: eigenvalues = $n ×$ variances along eigen-directions ⇒ all $\geq 0$)

> Mercer: the two conditions are also **sufficient** ⇒ no need to exhibit $\phi$

### Kernelizable pattern (final)

Any algorithm depending only on $x_i^\top x_j$ ⇒ replace by $k(x_i, x_j)$ ⇒ nonlinear version for free

Two ways to verify $k$ is valid

1. **Exhibit $\phi$** (works for polynomial; impractical for RBF)
2. **Mercer:** symmetry + PSD of $K$ on any dataset
